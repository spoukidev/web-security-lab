Why it works

In vulnerable mode, quote characters can close the intended string and append a Boolean expression. The demonstration makes the condition true for each fake user.

Why the fix works

Parameter binding sends the SQL program and input separately. The database treats the Boolean payload as literal search text, not executable SQL syntax.

Security lesson

Use parameterized queries for values, validate input as a secondary control, and grant database accounts only the minimum privileges required.
