Why CSRF works

Browsers may attach a user's cookies to a cross-site form submission. Without an unpredictable token, the server cannot distinguish that forged request from the user’s intended action.

Secure controls

Validate a synchronizer token on the server, use SameSite cookies, and validate Origin or Referer for sensitive state changes.

Security lesson

CSRF focuses on unwanted authenticated actions. It is distinct from XSS, which can run code in the victim’s page context.
