Reflected XSS

Input from the current request is rendered immediately. A crafted URL can therefore cause a browser to parse attacker-controlled markup.

Stored XSS

Input is saved first, then rendered to later visitors. This can create a broader and longer-lived impact than a reflected issue.

Remediation

Keep template autoescaping enabled and avoid safe for untrusted content. Use CSP as defense in depth, not as a replacement for output encoding.
