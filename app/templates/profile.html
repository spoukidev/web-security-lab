Authentication vs authorization

Authentication establishes an identity. Authorization decides whether that identity may perform this action on this specific object.

Root cause

Changing a direct reference such as /profile/1 to /profile/2 is effective only when the server misses its ownership check.

Security lesson

Check authorization on the server for every object access. Random identifiers can reduce guessing, but they never replace access control.
