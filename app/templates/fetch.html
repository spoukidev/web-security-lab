Root cause

Server-side URL fetching can bridge a browser into networks that are not directly reachable from that browser.

Secure controls

Secure mode uses HTTPS and hostname allowlists, rejects private and non-global resolved addresses, blocks redirects, and sets a timeout and 64 KiB response limit.

Defense in depth

Network segmentation still matters. The Docker mock has no host port, and the secure code independently rejects it.
